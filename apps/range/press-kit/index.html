Range Press Kit

Range makes it easy to generate a random number between two values. Simply enter a value for the start and end of the range and then select Generate. Range will then show you a random number in that range!

Releases

To find out whatʼs new in Range, please head to the releases page here.

Features

Random Number Generator

Range makes it quick and simple to generate any number for a given range. Simply type the start and end values and Range will do the heavy lifting.

Widget

Without launching the app, you can use the widget to generate a random number.

Apple Watch

Generate random numbers on your wrist with the Range Apple Watch app.

Menubar

Generate random numbers from anywhere with the Mac Menubar app.

Shortcuts

Use Siri and the Shortcuts app to generate random numbers.

Pricing

Range is available as a one-time purchase for $1.99/£1.99. Promo codes available upon request.

Compatibility

Range is available on iOS (18.0+), iPadOS (18.0+), macOS (15.0+), tvOS (18.0+), visionOS (2.0+) and watchOS (11.0+).

Technologies

Range has been built using SwiftUI, App Intents and WidgetKit.

Localisation

Range is localised in English.
