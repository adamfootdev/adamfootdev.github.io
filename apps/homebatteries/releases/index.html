HomeBatteries Releases

Version 4.0

14 September 2026

Sorting

Accessories can now be sorted by name, device type, battery levels, last charge/replacement date or battery type. This setting syncs via iCloud.

Battery Type Suggestions

Battery types are now suggested based on a local database and Apple Intelligence. There is also a corresponding Shortcuts action too.

Battery Life Estimations & Averages

Added estimated charge/replacement date and average battery life states to the Battery Trends section. Corresponding Shortcuts actions are also available.

Philips Hue

Added Philips Hue to 3rd party integrations. This means users running a Hue Bridge Pro will now see their batteries in HomeBatteries. Please note this only works whilst connected to the same network.

SOMA

Added SOMA to 3rd party integrations. Please note this only works whilst connected to the same network.

Battery Trends Shortcut

Added a new Shortcuts action to fetch a list of battery trends data. This also shows a graph snippet when run.

Shortcuts Snippets

Added a Shortcuts snippet to actions that return a battery level.

Room & Home Ordering

Rooms and homes can now be reordered from either the sidebar or room/home picker. This syncs via iCloud.

More

• Support for the OS 27 releases. • Added a context menu action to log a battery charge/replacement on an accessory’s row. • Added the ability to disable grouping by rooms so all accessories can be sorted overall. This syncs via iCloud. • Added the ability to show last battery charge/replacement date on an accessory’s row. This syncs via iCloud. • Showing the battery type on an accessory’s row can now be disabled. This syncs via iCloud. • Rooms can now be selected from the top toolbar on iPhone. • Notifications will now always be shown after the Refresh Data automation has been run instead of at random times so setting a time for the automation to run should now be the time you want a notification to appear. • If the Refresh Data automation has never run, a message will now be shown in-app to alert you. This can be dismissed and will only be shown once after having the app installed for over 24 hours. • Refreshed the underlying architecture of HomeBatteries to make it more stable and use less storage on your device. The Refresh Data automation has also been improved to prevent showing a timeout error. • Updated existing Shortcuts actions to better support the new version of Siri. • Accessories are now cached in Spotlight for quick launching. • Improved support for accessories that have not been configured correctly in Apple Home by manufacturers. • Improved support for widgets on Apple Vision Pro.

Version 3.1

9 January 2026

Low Batteries Section

Added a new Low Batteries section at the top of the accessories list screen to see at a glance which accessories will need attention soon. This section can be hidden in Settings > General.

Automatic Battery Type

Updating a battery type will now automatically set all other accessories with the same manufacturer & model to that battery type. This can be disabled in Settings > General.

More

• When running the Refresh Data automation, notifications will now be shown shortly after running if a notification has not already been triggered within the minimum alert interval. • Accessory rows on Apple Watch will now omit the room name.

Version 3.0

15 September 2025

Fall 2025 Update

• Updated to support Liquid Glass in the latest OS version with a refreshed user interface. • Added support for widgets in CarPlay. • Updated the app icon for Liquid Glass.

Version 2.1

16 September 2024

Fall 2024 Update

• Added support for battery-powered TVs, Speakers & Routers in the latest OS version. • Added dark & tinted app icons on iOS & iPadOS. • Tips now sync via iCloud so you’ll only see them on one device. • Added support for the latest version of iOS, iPadOS, visionOS & watchOS.

Version 2.0

18 March 2024

Battery Trends

HomeBatteries will now keep track of a HomeKit accessory’s battery level over time so you can view how long it lasts between charges/replacements. This data is available to view as a graph on the accessory details screen.

Log Charge/Replacements

Linked to the new Battery Trends feature is the ability to log when an accessory had its battery charged or replaced which is also visible on the same graph.

Apple Watch App

The Apple Watch app supports viewing all batteries at a glance. It will be highlighted yellow/red if it requires attention and also displays the battery type required too.

Redesigned iPad/Vision Pro App

On iPad & Apple Vision Pro, the app has been redesigned with a new 3 column layout to take advantage of the bigger space. In the sidebar, you can filter by rooms to quickly access accessories in that room. On iPhone, sections can be collapsed to access rooms quicker if you have a large number of accessories.

iCloud Sync

Accessory settings and trends data now sync over iCloud so you can view details on all compatible Apple devices. Notification settings will also sync over iCloud too.

More

• Added multiple new Shortcuts actions: log charge/battery replacement, fetch charge/replacement dates, set battery type, charging status, hidden status, set hidden status, identify accessory. • Added support for accessories that don’t expose a battery level percentage to HomeKit and only a Normal/Low value. • Low batteries now stand out easier in the app as accessories that are sufficiently powered will now be grey instead of green. • Accessories can now be renamed in the app by tapping the name on the accessory details screen. • Added the ability to quickly identify an accessory in the app. • Pull to refresh on the accessories list screen. • Onboarding process for new users. • Improved placeholder views when HomeBatteries doesn’t have access to HomeKit, a Home is empty or the user has no Homes in HomeKit. • Widgets & Shortcuts Actions are now much quicker to load available accessories. Widgets have also been tweaked slightly. • Improved the organisation of Shortcuts actions. • Added the ability to filter accessories by room, manufacturer and model in Shortcuts. • The Battery Accessories Shortcuts action has been marked as deprecated as the Find Accessory action is now preferred and offers the ability for filtering.
